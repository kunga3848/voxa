Installe l'app

Choisis le fichier qui correspond à ton appareil. Le téléchargement s'ouvre sur GitHub.

WindowsVoxa-Setup-1.0.0-beta.1.exe
AndroidVoxa-v1.0.0-beta.1.apk
Mac M1, M2, M3, M4Voxa-1.0.0-beta.1-arm64.dmg
Mac IntelVoxa-1.0.0-beta.1-x64.dmg
L'installation est bloquée ?
  • Windows : sur l'écran bleu SmartScreen, clique sur « Informations complémentaires », puis « Exécuter quand même ».
  • Mac : glisse Voxa dans Applications. Au premier lancement, fais clic droit sur Voxa › Ouvrir. Si macOS refuse encore, va dans Réglages Système › Confidentialité et sécurité › « Ouvrir quand même ».
  • Android : autorise l'installation d'applications provenant de ton navigateur quand le téléphone le demande.

Ces avertissements viennent du fait que la bêta n'est pas encore signée par Apple, Microsoft ou Google.

Active le moteur de voix

Pendant la bêta, les voix sont générées par le moteur Chatterbox hébergé sur Hugging Face. Il demande un jeton gratuit, à créer une seule fois.

  1. Crée un compte gratuit sur huggingface.co.
  2. Ouvre Settings › Access Tokens › New token, laisse le type Read, donne-lui le nom voxa et clique sur Create token.
  3. Copie le jeton, qui commence par hf_.
  4. Dans Voxa, ouvre Réglages, colle-le dans Jeton Hugging Face et clique sur Enregistrer.

Le quota gratuit permet quelques minutes de génération par jour. Si Voxa affiche « quota atteint », note-le dans ton retour et réessaie le lendemain.
